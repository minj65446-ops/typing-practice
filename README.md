# 打字练习 · Typing Practice

一个给手机用的打字练习网页：**免安装、打开就能用、可添加到桌面**。

## 功能

- ⌨️ 四种练习模式
  - **单词**：英文常用词
  - **句子**：英文句子
  - **符号**：代码符号（`if (a > b) { ... }`、SQL、Git 命令）
  - **文章**：中文文章（散文 / 小说 / 诗词 / 国学 / 新闻……）
- ⏱ 60 秒挑战（时间到自动结算）
- 📊 实时统计：速度（英文 WPM / 中文 字/分）、准确率、连击
- 🎯 逐字高亮：对了变绿、错了变红、当前字有光标
- 📚 错词本：英文模式自动记录错词，可"只练错词"
- 📱 手机优先：大字号、大按钮、支持手机输入法
- 🚫 无依赖、无统计、无广告，纯静态页面

## 怎么用

1. 打开网页：**https://minj65446-ops.github.io/typing-practice/**
2. 点「开始」，用键盘/输入法输入上方文字
3. 手机可以点浏览器菜单 → **添加到主屏幕**，像 App 一样打开
